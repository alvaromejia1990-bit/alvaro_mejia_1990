Cómo publicar el inventario actualizado

Sin Google Sheets, los cambios se guardan en este navegador. Para que todos los clientes vean el stock nuevo:

  1. Pulsa Descargar inventario.js.
  2. En GitHub abre data/inventario.js → Edit (o «Upload files» en la carpeta data) y reemplázalo.
  3. Haz Commit. En 1–2 minutos GitHub Pages publica el cambio.

Para inventario automático y compartido en tiempo real (cada venta descuenta stock para todos), activa Google Sheets siguiendo el README.
